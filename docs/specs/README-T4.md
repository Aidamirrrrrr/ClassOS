# ClassOS T4 — удалённое управление

Статус: **реализация собрана и покрыта доступными автоматическими проверками;
запуск на реальной Windows-машине и Windows CI ещё не выполнены.**

## Реализовано

- сетевые и локальные IPC-сообщения для старта, остановки и событий ввода;
- единственный владелец control-сессии на Student PC и явный отказ второму
  преподавателю, включая повторный старт уже активной сессии;
- передача указателя, кнопок мыши, прокрутки и клавиатуры через
  Teacher → Service → Session Host;
- нормализованные координаты с проверкой границ до вызова Win32;
- изоляция Win32 `SendInput` и окна-индикатора в `windows-platform`;
- обязательный topmost-индикатор `Teacher connected` в пользовательской
  сессии Student PC;
- отзыв управления и скрытие индикатора при Stop, закрытии TLS-соединения,
  потере IPC или завершении Session Host;
- структурированные audit-совместимые записи о старте и остановке;
- элементы управления в Teacher Console.

## Автоматически проверяется

- protobuf encode/decode для local IPC и сетевых control/input-сообщений;
- state machine: эксклюзивность владельца, отключение и запрет замены активной
  сессии;
- граничные нормализованные координаты;
- Rust workspace check/test/clippy и frontend production build;
- отдельный статический Windows cross-check crate-ов, содержащих Win32-код.

## Не проверено на реальном оборудовании

- полный LAN-цикл Start → mouse → click → keyboard → Stop;
- отображение и гарантированное закрытие индикатора в пользовательской
  Windows-сессии;
- ограничения UIPI для elevated/admin-окна;
- отключение Teacher и аварийное завершение Session Host во время active control;
- совместная работа двух Teacher Console и поведение на DPI/нескольких мониторах.

До этих проверок T4 нельзя считать подтверждённым на целевой среде.
